# 열공 · 기말고사

2026년 11월 6일 제공된 사진 21장을 바탕으로 만든 기말고사 영어 학습 사이트입니다. 중간고사 지문과 어법 특별 자료는 현재 목록·본문·사진에서 제거했습니다.

## 범위

- 14과 빈칸 추론 (2): 09–26번, 18지문. 사진에 잘려 보이는 08번은 제외했습니다.
- 17과 주어진 문장의 위치: 01–24번, 24지문.
- 18과 문단 요약: 01–12번, 12지문.
- 총 54지문, 389문장.

사진의 연필 체크·밑줄·풀이 흔적을 기준으로 13지문에 **수업한 지문**을 표시했습니다. 14과 10·15·17·18·19·20·23·25번, 17과 01·02·04·12·21번입니다. 표시가 없다는 것이 미수업을 뜻하지는 않습니다. 개인 학습 완료 기록과 구별되는 자료 속성이며 목록의 보기 메뉴에서 모아 볼 수 있습니다.

## 사용

지문을 열면 영어 각 문장 아래 직역이 표시됩니다. 직역을 숨기거나 글자 크기를 조절할 수 있습니다. 영어 단어를 누르면 한글 뜻이 아래에 펼쳐지고 다시 누르면 닫힙니다. 다른 단어를 누르면 앞의 뜻은 닫힙니다. 문장 번호를 누르면 해당 문장의 해석과 앞뒤 연결로 이동합니다. 해설·순서·어법 영역의 영어에도 적용됩니다. 키보드 Enter/Space로 열고 Escape로 닫을 수 있습니다.

- 지문 분석: 전체 흐름, 쉬운 설명, 문장 연결, 전환·범위, 지시·구문, 핵심 정리.
- 수능 유형 대비: 예상 주제·요지·제목, 순서 구획, 삽입·빈칸 근거, 주요 어법·어휘. 새로운 문제를 출제한 영역은 아닙니다.
- 사진 원본: 페이지에 걸친 본문을 확인할 수 있습니다. 14과 빈칸은 답을 채웠으며 17과는 주어진 문장을 제자리에 넣고 색으로 표시했습니다. S 번호는 학습용 문장 번호이고 원래 삽입 위치 ①–⑤와 다릅니다.
- 보관·완료·메모는 각 사용자의 현재 브라우저에만 저장됩니다. 기기 간 동기화는 없으며 브라우저 데이터를 지우면 기록도 사라집니다. 기말고사 전용 저장 키와 새 지문 ID를 사용하므로 중간고사 기록이 섞이지 않습니다.

정답 해설은 제공된 본문을 읽고 작성했습니다. 별도의 공식 정답표를 연결한 자료는 아닙니다. 어법·어휘는 대표 요소를 정리한 것으로 모든 요소를 망라하지는 않습니다.

## 실행 및 관리

정적 사이트로 서버 API나 빌드가 필요 없습니다. `python -m http.server 8765`로 로컬 실행하거나 GitHub Pages에서 이용합니다.

- `data/index.js`: 목록과 수업 표시 등 메타데이터.
- `data/exams/final-blank.js`, `final-insertion.js`, `final-summary.js`: 본문과 학습 해설. 유형을 열 때 필요한 파일만 불러옵니다.
- `assets/sources/00.jpg`–`20.jpg`: 제공된 사진 원본 사본.
- `script.js`, `style.css`: 탐색, 반응형 화면, 개인 기록.
- `node scripts/reindex.cjs`: 본문에서 목록 재생성.
- `node scripts/validate.cjs`: 시험 범위, 문장 번호, 인용, 구획, 사진, 수업 표시 검사.

자료와 사진을 변경할 때 `index.html`과 `script.js`의 버전 문자열도 함께 갱신합니다.

## 단어 뜻

`data/word-meanings.js`에 현재 자료의 2,671개 단어 형태를 수록했습니다. 외부 번역 API 없이 조회하며 지문 주요 어휘의 뜻을 우선합니다. 그 밖에는 일반 사전 뜻이므로 문맥에 맞는 의미는 문장 해석과 함께 확인하세요. 새 지문을 추가할 때 사전 범위도 갱신해야 합니다. 사전 자료의 출처·변경·라이선스는 [DICTIONARY-NOTICE.md](DICTIONARY-NOTICE.md)를 확인하세요.

`node scripts/validate-words.cjs`로 본문 전체의 단어 뜻 누락을 검사할 수 있습니다.
